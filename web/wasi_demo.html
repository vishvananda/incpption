cppinception

Meet cppgm, a C++ compiler built for fast compilation—fast enough to compile itself in your browser.

Start with cppgm already compiled to WebAssembly by cppgm itself. Watch it rebuild itself here and match every output byte. Then use your new compiler to build OpenLara to WebAssembly and play it in this same browser.

See how it works ↓

Everything runs locally in your browser: compiling, linking, checking, and playing. The server only delivers static files. No code is sent to a server to compile or run.

What matching bytes tell us

Each corresponding object and final WebAssembly module is compared as actual bytes. Matching outputs show that this source, toolchain, and build profile reproduced the same result across these builds.

A match does not prove that the compiler is bug-free, secure, or correct for every program.

Technical details & downloads

The shipped WebAssembly compiler was built by cppgm on Linux. It rebuilds itself here. You can enable a second rebuild for deeper validation.
